# CORS

- Cors(Cross-origin Resource sharing) é uma ferramenta de segurança que permite que uma página web acesse recursos de outra origem

-- Cors é ativado quando um pagina tenta acessar recursos de uma origem diferente daquela que serviu

-- Cors adiciona cabeçalhos HTTP que informam ao navegador se deve permitir o acesso aos dados solicitados

-- Os cabeçalhos CORS incluem Acces-Control-Allow-Origin, Access-Control-Allow-Credentials, entre outros

-- O servidor verifica o cabeçalho da origem atual e responde com os dados solicitados

-- O navegador visualiza os cabeçalhos da solicitação de controle de acesso e compartilha os dados retornados com a aplicação cliente
